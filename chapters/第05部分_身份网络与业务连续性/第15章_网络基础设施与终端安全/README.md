# 第15章　网络、基础设施与终端安全

## 核心定位

本章覆盖企业基础安全能力的工程实现层：本地与混合网络架构、分段与微隔离、边界与流量防护、邮件安全与反钓鱼、终端安全管理、补丁运营、出网与 DNS 治理、无线与网络准入、远程接入、数据中心基础设施，以及支撑这一切的资产与暴露面治理。

与相邻章节的分工：云侧的网络与工作负载安全由 5.3、5.4 承担；移动设备策略与远程办公的组织决策见 10.5；检测规则与监控见 11.3、11.7；漏洞的发现与优先级见 11.8，本章 15.6 是其下游的交付执行。

本章的一贯主张是：**企业基础安全的绝大多数缺口不是"做不到"，而是"没人去看"**——能力普遍已部署，配置普遍停在最保守的档位，而没有人的职责是去检查这件事。因此每一节除给出技术做法外，都会回答"这项工作归谁、怎么度量它是否真的生效、停滞时用什么机制让停滞变得可见"。

## 核心术语表

| 术语 | 全称 | 说明 |
|------|------|------|
| NGFW | Next-Generation Firewall | 下一代防火墙，具备应用识别与身份关联能力 |
| SPF | Sender Policy Framework | 声明哪些 IP 有权代表本域发信 |
| DKIM | DomainKeys Identified Mail | 对邮件签名，可穿越转发 |
| DMARC | Domain-based Message Authentication, Reporting and Conformance | 要求认证结果与可见发件人对齐，并规定失败处置 |
| BEC | Business Email Compromise | 商业邮件诈骗，不含恶意代码的资金类欺诈 |
| SEG / ICES | Secure Email Gateway / Integrated Cloud Email Security | 网关式与 API 式邮件防护 |
| EPP / EDR | Endpoint Protection Platform / Endpoint Detection and Response | 阻断与检测响应，两组独立策略 |
| UEM | Unified Endpoint Management | 统一终端管理 |
| OOB | Out-of-Band Management | 带外管理，不依赖操作系统的管理通道 |
| MAB | MAC Authentication Bypass | MAC 认证旁路，用于无法认证的设备 |
| PDNS | Protective DNS | 保护性 DNS，在解析阶段阻断恶意域名 |
| SWG | Secure Web Gateway | 安全 Web 网关 |
| SSE / SASE | Security Service Edge / Secure Access Service Edge | 云交付的安全能力集合，后者含网络能力 |
| ZTNA | Zero Trust Network Access | 按应用而非按网段授权的接入方式 |
| CAASM / EASM | Cyber Asset / External Attack Surface Management | 内部视角与攻击者视角的资产管理 |
| MCP | Model Context Protocol | 智能体调用工具的事实标准协议；MCP server 在本章按一类需纳管的资产处理 |
| AI 网关 | AI / LLM Gateway | 统一代收模型调用的内部出口，本章用它把模型 API 出网从加密流量变成可审计的调用 |
