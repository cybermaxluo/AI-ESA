## 部分定位

全书前五个部分讲的是"做什么"和"怎么做"，本部分讲"靠谁做、拿什么做、怎么让它持续下去"。安全组织的形态决定了能力上限，能力模型决定了招得到什么人，预算决定了能推进多快，而文化决定了这些投入会不会在第二年被稀释。本部分也是全书唯一以人和组织为主体的部分。

适用读者：安全负责人（CSO/CISO）、安全团队管理者、HR 与组织发展伙伴、准备走向管理岗的资深工程师。

前置要求：建议先通读第1部分，理解安全在企业架构中的定位；其余各章可按需查阅。

与其他部分的关系：

- 为全书各技术域提供组织承载、人才供给与预算依据
- 把第1部分的治理结构落实为具体的团队职能与汇报线
- 将第4部分的运营度量转化为向管理层与董事会的沟通语言
