## 部分定位

本部分是全书的地基。它不讲具体技术，而是先把安全放回企业架构里——安全架构不是独立王国，它嵌在业务架构与 IT 架构之上；治理不是写文档，而是让风险、合规、政策三条线在同一套流程里咬合；而 BISO 模式回答的是"安全团队怎么真正进入业务的决策现场"，这是所有技术控制能否落地的前提。

适用读者：安全负责人（CSO/CISO）、安全架构师、GRC 与合规负责人、业务安全伙伴（BISO）。

前置要求：无。本部分是全书起点，建议顺序阅读。

与其他部分的关系：

- 向第2部分输出安全架构的顶层原则与嵌入逻辑
- 为第3部分的数据分类分级提供治理与合规依据
- 为第4部分安全运营提供风险优先级与度量口径
- 为第7部分组织建设提供治理结构与角色定义
