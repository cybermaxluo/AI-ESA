## 部分定位

本部分覆盖数据与信息的全生命周期防护。第8章处理"未授权访问"这一面：分类分级、加密与密钥、访问控制、监控审计、跨境合规，控制落在系统与数据存储上。第10章处理"已授权者滥用与外带"这一面：文档标签、IRM/DRM、DLP 运营、内部风险，控制落在人与终端上。第9章横跨两者，从个人数据的法律义务出发反向约束技术设计。

适用读者：数据安全负责人、隐私官（DPO）、数据治理与合规团队、安全运营工程师。

前置要求：建议先完成第2章（GRC 治理）与第4章（安全架构与工程），理解风险口径与架构方法。

与其他部分的关系：

- 承接第2部分的加密、身份与云数据保护能力
- 向第4部分提供数据侧的检测信号与事件分类
- 为第6部分的 AI 数据安全提供分类分级与访问控制底座
